# 🍗 KFC Billing Counter

A simple console-based **KFC Billing Counter application developed using Java**.

This project allows users to place an order, receive a token number, make a payment using the token number, and exit the billing system.

## 📌 Project Overview

The application provides a simple menu-driven interface with three options:

1. Place Order
2. Payment
3. Exit

The project demonstrates basic Java concepts such as `HashMap`, `Scanner`, methods, loops, conditional statements, and switch statements.

## ✨ Features

- 🍗 Display KFC menu
- 🛒 Place an order
- 🎟️ Generate token numbers automatically
- 💳 Verify payment using token number
- ⚠️ Handle invalid menu items
- ⚠️ Handle invalid token numbers
- 🔄 Continuous menu-driven system
- 🚪 Exit option
